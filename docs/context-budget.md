# 上下文预算

每轮对话都会加载的内容只该包含「每次都成立」的约束；其余按需加载。模型升级后按本页重跑一遍。

## 度量

```bash
python -B scripts/context_budget.py
```

输出每轮（`AGENTS.md` + 25 条描述）与按需（正文、references、仓库文档）的字符数。描述超预算时退出 1。

预算：

- 自动调用型 `description` ≤ 140 字符，手动触发型 ≤ 100 字符。
- `AGENTS.md` 只放每轮都需要的边界，目标 ≤ 500 字符。
- 正文与 references 没有硬上限，但只在对应分支需要时加载。

## 判断位置

| 内容 | 位置 |
| --- | --- |
| 每次对话都成立的项目边界、不可逆操作授权 | 根 `AGENTS.md` |
| 跨项目的硬约束（Push/发布/删除/花钱/提权） | 全局规则 |
| 项目命令、验证、发布、分支流程 | `CONTRIBUTING.md` / 项目指南 |
| 改某类文件才需要的格式清单 | `docs/agent/*.md`，由根规则指向 |
| 同一输入总是同一输出的检查 | 脚本（如 `validate_skills.py`、`context_budget.py`） |
| 需要判断的领域知识 | Skill 正文 |
| 只在特定分支/异常时需要的细节 | Skill `references/` |
| 描述里的近义词与场景举例 | 正文 `## When to use` |

## 五种处置

- **修**：内容已过期或与其他位置不一致。
- **删**：删掉后行为不变（模型默认会做、其他地方已写、同段重复）。
- **挪**：整行搬到正确位置，不边搬边改写；不可逆规则原样搬。
- **改写**：同位置换成目标描述（做什么、何时完成、要什么证据）。
- **保留**：偏好、被否方案、机器环境、不报错的坑、半句约束、不可逆规则、带日期决策。

## 不删清单

- 偏好与被否掉的方案及原因。
- 机器环境与路径符号。
- 不报错的坑，以及看着像出错其实正常的现象。
- 「从不写入」「不上传」「不覆盖」「不删除」这类半句约束。
- 删除数据、花钱、发布、提权、改写已推送历史的规则。
- 带日期的拍板决策记录。

## 验证

1. 跑 `validate_skills.py`、单测、`context_budget.py`、`git diff --check`。
2. 新规则里的 glob 必须命中真实文件；搬走后 grep 旧文件名，确认还有指针。
3. `git diff -U0` 提取所有消失行，逐行对应到清单；无对应项的恢复。
4. 交给未参与精简的 Agent：只给消失行与仓库，按关键名词搜索；意思在仓库任何地方都找不到的恢复。
5. 暗号验证：在新文件埋一个唯一字符串，开新会话读一个匹配文件并问暗号，再读不匹配文件做反向对照。

## 模型升级后

1. 先记录基线：`context_budget.py` 的四个数字。
2. 重读 `AGENTS.md` 与全部描述，只处理「每轮加载」的部分。
3. 对新模型已稳定做到的行为重新判断：以前需要写的步骤，现在可能可以删。
4. 按本页位置表搬运，先搬后压。
5. 重跑验证，比较前后数字。
