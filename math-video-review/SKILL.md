# Math Video Review

对数学讲解视频做两阶段审校：转写后的轻审和发布前终审。输出证据化问题清单，不替用户重写讲解。

## 何时使用

- ASR 完成后检查核心术语、公式和高风险片段
- 剪辑完成后核对字幕、板书、语音和推导
- 生成 Manim 候选清单

## 证据标签

每条结论标明：

- **确认**：音频、板书或可靠课程来源足以支持
- **疑似**：存在冲突但证据不足，需要用户判断
- **未核对**：缺少可读取的音频、画面或来源

始终分开记录“实际说了什么”和“数学上应如何表述”。

## Light review

1. 读取课程词表、当集主题和原始转写。
2. 用本地规则扫描术语变体、符号异常、低置信片段和重复文本。
3. 只打开命中的上下文；必要时抽取最小音频或画面片段。
4. 生成候选表：时间戳、原文、候选解释、证据、状态。
5. 用户确认后才形成 episode 级修正规则。

完成条件：核心概念均被检查；每个修改都有上下文证据和变更记录。

## Final review

1. 以剪辑轴字幕为准检查断句、越界、屏幕可读性和公式字符。
2. 对照语音和板书核对所有 Light review 高风险项。
3. 验算视频中明确出现的定义、等式和证明步骤；优先自己推导，其次查课程官方材料。
4. 课程版本或 lecture 对应关系必须有官方来源；本地资料出现 Fall 2006、18.01SC Fall 2010 等冲突时标为 `unknown`，不自行合并。
5. 输出勘误：事实错误、口误、ASR 错误、表达建议、已验算通过项分别列出。

完成条件：所有阻断项已解决或用户明确接受；未知项保持未知。

## API 升级策略

本地脚本负责筛选、检索、格式检查和确定性换字。需要语义判断时先用当前会话能力；只有本地模型质量不足且判断会影响成片时，才向厂商 API 提交最小文字窗口。默认不上传视频、音频、完整字幕或课程私有材料。

## Manim 候选

终审后默认只生成候选，不写动画代码。每个候选包含：

- 对应时间与概念
- 动画要回答的问题
- 静态板书的局限
- 建议视觉变化
- 所需公式与来源
- 预计场景数和时长

优先选择动态关系、极限过程、几何变换和不变量；纯定义朗读或静态公式不因“能画”就进入候选。

## 输出格式

```markdown
| 时间 | 类型 | 原内容 | 证据 | 建议 | 状态 |
|---|---|---|---|---|---|
```

最终报告还需列出：已核对范围、未核对范围、课程来源版本、用户确认记录和 Manim 候选。

## Pitfalls

- 不把 ASR 的高置信度当成数学正确性。
- 不用全局词典替代上下文判断。
- 不因字幕已修改就声称口误已解决；成片注释方式由用户决定。
- 看不到画面时明确写“未核对”，不从转写猜板书。
