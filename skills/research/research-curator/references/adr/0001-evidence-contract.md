# ADR 0001: Explicit evidence contract
Status: accepted

Use Go standard library for a portable ledger, strict schema validation and deterministic transformations. Human/agent retrieval supplies sources, exact quotes, qualifiers and explicit provenance. Exact canonical URLs and exact content SHA256 can establish duplicates; semantic syndication and circular citations require explicit upstream IDs. A shared upstream root is one evidence origin, not independent corroboration. Cycles remain visible as warnings. Separate structural validation, recorded retrieval verification and coverage from truth. Finalization never fabricates stages or research. Offline rendering is an adapter over the JSON contract.
